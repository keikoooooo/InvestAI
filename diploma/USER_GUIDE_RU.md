# Полное руководство пользователя InvestAI

## 1. Описание системы
InvestAI — веб-приложение для учебного инвестиционного анализа. Система объединяет:
- личный кабинет инвестора;
- портфельную аналитику;
- обзор рыночных данных;
- AI-чат для подсказок;
- персональные настройки риск-профиля.

Приложение состоит из frontend (интерфейс) и backend (API + PostgreSQL).

## 2. Функциональные возможности
Пользователю доступны:
- регистрация и авторизация;
- первичная настройка (онбординг);
- дашборд с ключевыми метриками;
- детальный просмотр активов портфеля;
- анализ отдельного инструмента;
- раздел обзора рынка;
- AI-ассистент с историей диалога;
- редактирование профиля и предпочтений.

## 3. Минимальные требования
Для локальной работы нужны:
- Node.js и npm;
- Go (для backend);
- PostgreSQL;
- доступ к портам 5173 (frontend) и 8080 (backend) по умолчанию.

## 4. Подготовка к запуску

### 4.1 Настройка базы данных
1. Создайте БД PostgreSQL.
2. Установите переменную окружения `DATABASE_URL`.
3. Примените SQL-скрипты:

```bash
psql "$DATABASE_URL" -f backend/db/schema.sql
psql "$DATABASE_URL" -f backend/db/seed.sql
```

### 4.2 Переменные окружения backend
Обязательная:
- `DATABASE_URL` — строка подключения к PostgreSQL.

Опциональные:
- `PORT` — порт backend (по умолчанию `8080`);
- `DEFAULT_USER_EMAIL` — email пользователя по умолчанию (по умолчанию `john.doe@example.com`);
- `BYBIT_ENABLED` — включение фонового поллера Bybit (`true/false`);
- `BYBIT_BASE_URL`, `BYBIT_CATEGORY`, `BYBIT_QUOTE`, `BYBIT_POLL_INTERVAL` — параметры поллера рынка.

### 4.3 Переменные окружения frontend
- `VITE_API_BASE_URL` — базовый URL API.

Пример (`.env` в корне frontend):

```env
VITE_API_BASE_URL=http://localhost:8080/api/v1
```

## 5. Запуск приложения

### 5.1 Backend
```bash
cd backend
go mod tidy
go run ./cmd/server
```

### 5.2 Frontend
```bash
npm i
npm run dev
```

### 5.3 Проверка
- Frontend: `http://localhost:5173`
- Health backend: `http://localhost:8080/health`

## 7. Пользовательские сценарии

### 7.1 Вход в систему
1. Откройте стартовую страницу.
2. Введите email и пароль.
3. Нажмите «Войти».
4. После успешной авторизации откроется «Панель управления».

### 7.2 Регистрация нового пользователя
1. На странице входа переключитесь на «Регистрация».
2. Заполните имя, email, пароль.
3. Нажмите «Создать аккаунт».
4. После регистрации система переводит пользователя в онбординг.

### 7.3 Онбординг
Онбординг состоит из 4 шагов:
1. Выбор толерантности к риску (консервативная/умеренная/агрессивная).
2. Выбор инвестиционной цели.
3. Указание уровня опыта.
4. Выбор начальной суммы инвестиций.

После нажатия «Завершить настройку» данные сохраняются и открывается дашборд.

### 7.4 Панель управления (Dashboard)
Раздел показывает:
- общую стоимость портфеля;
- суммарный финансовый результат;
- изменение за день;
- уровень уверенности AI;
- график динамики портфеля;
- структуру распределения активов;
- блок AI-инсайтов;
- список топ-позиций.

Из дашборда можно перейти:
- в «Портфель»;
- в «AI Ассистент»;
- на страницу анализа конкретного актива.

### 7.5 Портфель
В разделе «Портфель» доступны:
- сводные показатели (стоимость, P/L, количество активов);
- график динамики;
- таблица активов с метриками;
- поиск по тикеру/названию;
- фильтрация по типу (все, акции, облигации, крипто);
- переход в карточку актива.

Для каждой позиции отображаются:
- количество;
- средняя цена;
- текущая цена;
- общая стоимость;
- прибыль/убыток;
- доля в портфеле.

### 7.6 Анализ актива
На странице актива пользователь видит:
- название и тикер;
- текущую цену и изменение;
- AI-рекомендацию и confidence;
- блок объяснения и рисков;
- график цены (включая MA20/MA50);
- объем торгов;
- технические индикаторы;
- диапазон 52W.

### 7.7 Обзор рынка
Раздел «Обзор рынка» содержит:
- рыночные индексы;
- intraday-график;
- Top Gainers и Top Losers;
- динамику секторов;
- AI-сигналы рынка.

### 7.8 AI-ассистент
Возможности:
- отправка свободных вопросов по инвестиционной теме;
- быстрые шаблоны вопросов;
- отображение истории сообщений;
- индикация времени отправки сообщений.

Важно: ответы AI имеют информационный характер.

### 7.9 Настройки
Вкладки настроек:
- `Profile` — имя, email, телефон;
- `Investment` — риск-профиль и инвестиционная цель;
- `Notifications` — параметры уведомлений;
- `Security` — раздел безопасности (в текущей версии информационный);
- `Preferences` — валюта, компактный вид, показ процентов.

После изменения параметров используйте кнопку сохранения.

### 7.10 Тема и выход
В боковом меню:
- переключатель светлой/темной темы;
- кнопка «Выход» для завершения сессии.

## 8. Структура навигации
Основные маршруты интерфейса:
- `/` — вход/регистрация;
- `/onboarding` — первичная настройка;
- `/dashboard` — панель управления;
- `/portfolio` — портфель;
- `/asset/:symbol` — анализ актива;
- `/market` — обзор рынка;
- `/ai-assistant` — AI-чат;
- `/settings` — настройки.

## 9. Сообщения об ошибках и диагностика

### 9.1 Частые проблемы
1. `DATABASE_URL is required`
Причина: не задана переменная окружения backend.
Решение: установить `DATABASE_URL` и перезапустить backend.

2. Frontend не получает данные
Причина: неверный `VITE_API_BASE_URL` или backend не запущен.
Решение: проверить URL API и доступность `http://localhost:8080/health`.

3. Ошибка входа демо-пользователя
Причина: не загружен `seed.sql`.
Решение: повторно применить `backend/db/seed.sql`.

4. Пустые или нестабильные рыночные данные
Причина: отключен/недоступен поллер внешнего источника.
Решение: использовать seed-данные или проверить переменные `BYBIT_*`.

## 10. Ограничения текущей версии
- Кнопки `Add to Watchlist`, `Trade`, `Export`, `Filter` в ряде экранов являются UI-заготовками без отдельного серверного workflow.
- Раздел `Security` пока без полноценного управления паролем и 2FA.
- AI-ответы формируются по внутренним данным системы и не являются брокерской рекомендацией.

## 11. Безопасность и ответственность
- Не вводите чувствительные данные в AI-чат без необходимости.
- Используйте сложные пароли для реальных сред.
- Финансовые решения принимайте только после собственной проверки и анализа рисков.

## 12. Контрольный чек-лист для пользователя
Перед началом работы убедитесь, что:
1. Backend запущен и отвечает на `/health`.
2. Frontend открыт по `http://localhost:5173`.
3. Указан корректный `VITE_API_BASE_URL`.
4. Загружены `schema.sql` и `seed.sql` (для демо).
5. Авторизация проходит успешно.

После входа:
1. Пройдите онбординг.
2. Проверьте дашборд и состав портфеля.
3. Откройте минимум один актив и изучите рекомендации.
4. Настройте профиль и уведомления в `Settings`.
